# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities privately. Do **not** open a public GitHub issue.

Preferred options:

1. [GitHub Security Advisories](https://github.com/inerba/filament-db-config/security/advisories/new)
2. Email: inerba@gmail.com

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any known mitigations or suggested fixes

You can expect an acknowledgement within 7 days. We will keep you informed about the progress toward a fix and a coordinated disclosure date.
